# WP Rocket | Custom LazyLoad Placeholder

Replace WP Rocket's default LazyLoad placeholder with a transparent 1×1 GIF.

This helper resolves an issue where images can appear at incorrect sizes while
LazyLoad is active, sometimes correcting themselves only after the browser
window is resized.

To be used with:

- WP Rocket's **Enable for images** LazyLoad option.
- Websites affected by the issue described in
  [Images are incorrect sizes when LazyLoad is active](https://docs.wp-rocket.me/article/1638-images-are-incorrect-sizes-when-lazyload-is-active).

## Installation

1. Download `wp-rocket-custom-lazyload-placeholder.zip`.
2. In WordPress, go to **Plugins > Add New > Upload Plugin**.
3. Upload the ZIP file and activate **WP Rocket - Custom LazyLoad Placeholder**.
4. Clear the WP Rocket cache.

No configuration is required. The helper applies the custom placeholder
automatically while it is active.
